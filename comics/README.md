# ことねや・週刊4コマ バックナンバー更新手順
本ディレクトリは公開済み4コマを話数ごとにまとめるための入口です。
第1話「儲かった。でも、なぜ？」は話数と題名のみ確定。画像・公開日・個別X投稿URLは未照合です。
画像の確認前に架空の投稿日・セリフ・作品・サムネイルを作らないでください。
原画に本名・勤務先・勤務先を特定できる情報が含まれていないか確認し、公開用正規画像のみを採用します。
画像確認後は
1. assets/comics/001.png に正規画像を配置（画質と文字は改変しない）
2. comics/001/index.html を作成し、固有タイトル、meta description、canonical、OGP画像、WebPage/Articleなど実態に合った構造化データと本文を入れる
3. comics/index.html の第1話から個別ページへ直接リンクし、元のX投稿を併記する
4. sitemap.xml に /comics/001/ を追加する
5. NEWSデータは確定公開日のみ更新
6. GitHub Pagesで画像とリンク・スマホでの表示をチェック
※ 検索結果に関する保証はできず、Google側のクロールを待つ必要があります。
