## 2. 毎週水曜日の4コマ運用（最重要）

**現状：Xの公式タイムラインはトップに埋め込み済みだが、Xの投稿だけで静的な`/comics/`ページに新話が自動登録される仕組みはない。自動連動したと誤認しないこと。**

1. **水曜日7:00（日本時間）**：既存の「ことねや週刊4コマ制作」タスクが新作4コマ画像とX投稿本文をセットで準備する。
2. **水曜日18:00（日本時間）**：本人がX公式アカウントに**手動投稿**。Xの自動投稿はしない。
3. **X公開後**：採用確定した原画、新話番号、タイトル、サイト用解説、可能ならX投稿URLを揃える。必要な原画がこの会話から参照できない場合は、画像を改めて共有してもらう。**無断で画像を作り直さない**。
4. **HP更新**：承認済み画像を`assets/comics/NNN.webp`に置き、`comics/NNN/index.html`、`comics/index.html`、前話の次話リンク、`index.html`の話数表示と導線、`sitemap.xml`を同期更新する。必要に応じて`news/index.html`も更新。
5. **更新後検査**：画像・タイトル・URL・前後リンク・新着順・モバイル表示・SEOメタ情報・構造化データ・サイトマップを確認。GitHubの変更と実際の公開表示を区別して報告する。

次の追加話数候補は**第5話（`005`）**。実際の採用作品の番号・タイトルを優先し、すでにあるものを上書きしない。

### 投稿文の固定事項
- 毎回 `LINEスタンプ販売中！ https://x.gd/8R4SB` を入れる。
- 毎回 `#ことねや #4コマ漫画` を入れる。
- Xの文字数制限を守る。
- 投稿本文と画像は必ずセットで準備する。
- Xの手動投稿とWebの反映を別工程として扱う。

## 3. デザイン・作品上の固定ルール

- 既存のサイトのデザイン・ロゴ・ブランドイメージを勝手に変えない。
- 原画はユーザーが指定した**いっかい/Kaz作画マスター**および**こと・ね・やROBO作画マスター**を厳守する。採用済みの正規画像を使用。
- 4コマ題材は、普遍的な経営・仕事・お金・管理会計の「なぜ？」。**現在の勤務先、製材業、原木輸入に寄せない**。
- 「ことねや式」の基本は「気づく → 問い直す → 確かめる → やってみる」。スローガンは「できるかな⁉︎をカタチに！」。
